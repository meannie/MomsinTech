# Privacy and safe sharing

Work Receipts may contain employer-confidential, customer, personnel, compensation, security, health, or family information.

## Before capture

Do not ask for secrets or unnecessary identifying information. If sensitive detail is not needed, suggest a category or placeholder such as `Private client`, `regulated customer`, or an approximate range.

## Visibility labels

- **private:** retain only in the user's private vault
- **internal-safe:** suitable for the user's organization, not automatically public
- **public-safe:** reviewed for external sharing
- **review-needed:** sensitivity or authorization is unclear

Treat unlabeled new receipts as `private` by default.

## Before public output

Check for names, unreleased plans, proprietary metrics, security details, customer data, personnel information, and information covered by an NDA or workplace policy. Redact, generalize, or ask the user to review it. A `public-safe` label is helpful context, not a guarantee.

## Provider disclosure

Do not promise that information “stays local” or that an AI provider does not retain it. Explain that processing and retention depend on the user's provider, plan, workspace, and settings. The user controls where the portable vault is stored and whether it is uploaded again.
